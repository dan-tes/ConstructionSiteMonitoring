# СтройМонитор: frontend

SPA на React 19, TypeScript, Vite и Tailwind.

```bash
cp .env.example .env   # VITE_API_URL, по умолчанию http://localhost:8000
npm install
npm run dev            # http://localhost:5173
```

Доступны также `npm run build`, `npm run lint` и `npm run preview`.
Работа с API находится в `src/api/`, подробнее в [docs/api.md](../docs/api.md).
