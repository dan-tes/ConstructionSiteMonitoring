# Модуль 2б. Фаза по снимку (visual_phase)

Код: `services/visual_phase/`. Обучение: `phase_determination/visual_state_pretraining.ipynb`,
`visual_phase_timelapse.py`, `clip_visual_eval.py`, `build_visual_ensemble.py`.

## Зачем

Модель по технике плохо различает поздние фазы. Каркас, кладка и отделка
месяцами выглядят для неё одинаково: башенный кран и рабочие. При этом на
самом снимке эти фазы хорошо видны: леса, фасад, остекление. Этот модуль
даёт второй сигнал, который не зависит от детекции техники.

## Как работает

Модуль — ансамбль из трёх участников с равными весами, объединённых
лог-линейно:

1. **DINOv2 ViT-S/14 + логистическая регрессия.** Энкодер дообучен
   self-supervised методом (SimSiam) примерно на 10 тыс. неразмеченных фото
   строек.
2. **SigLIP ViT-B-16 + логистическая регрессия.**
3. **SigLIP zero-shot** по текстовым описаниям фаз. Это единственный
   участник, который знает фазу Preconstruction.

Головы обучены на кадрах 60 размеченных таймлапсов строек: 14 основных
роликов и 46 с YouTube. На видео модель берёт 6 кадров и усредняет
результат. На выходе — вероятности по фазам. Сервис `phase` использует их
как второй сигнал.

## Путь к текущей версии

| Версия | Точность по кадрам (held-out) |
| --- | --- |
| k-means по эмбеддингам DINOv2, кластеры размечены вручную (попадает только в 4 фазы из 10) | 24.8% |
| DINOv2 + линейная голова, 14 роликов | 50.6% |
| SigLIP + линейная голова, 14 роликов | 59.7% |
| SigLIP zero-shot, без обучения | 26.5% |
| на 60 стройках, 10 фолдов по стройкам: DINOv2 / SigLIP | 50.1% / 54.0% |

По дням на 60 стройках: DINOv2 53.4%, SigLIP 55.5%, SigLIP zero-shot 21.4%.
Сам по себе zero-shot слабый, но в ансамбле он добавляет качества: к
результату «техника + DINOv2» он прибавляет 4–5 п.п.

Отдельно модуль используется только внутри объединения с техникой, см.
[phase.md](phase.md).

## Ограничения

- Размеченных фото нет, есть только кадры таймлапсов. Фазы Preconstruction
  в роликах нет вообще, а MEP и Commissioning — лишь несколько десятков
  дней.
- Класса «не знаю» нет: любой снимок будет отнесён к какой-то фазе.
- `confidence` — это не откалиброванная вероятность.
