# Модуль 3. Текущая фаза проекта (phase)

Код: `services/phase/` (`worker.py`, `model.py`, `features.py`, `fusion.py`).
Обучение: `phase_determination/construction_phase_training.ipynb`,
`train_phase_v2.py`, `finetune_timelapse.py`. Оценка: `eval_all.py`.

## Зачем

Главный ответ системы — на какой из 10 фаз сейчас находится стройка. От
него зависят прогноз отставания, отчёт «план — факт» и графики на
странице проекта.

## Как работает

**Модель по технике (ConstructionPhaseModel).** На вход подаётся окно из
128 дней ежедневных счётчиков техники. Дни без записи в журнале
заполняются значениями последнего известного дня (forward-fill), и модель
знает, какие дни реальные, а какие заполненные. Дополнительно модель
получает описание фаз из плана: ожидаемую технику и текстовые эмбеддинги
MiniLM. Версии модели:

- **v1:** обучена на синтетике вида «работы → ожидаемая техника →
  события».
- **v2:** обучена на выходе симулятора детектора, то есть на том, что
  реально приходит из `vision`.
- **v2_ft:** v2, дообученная на реальных рядах «день → счётчики YOLO» из
  таймлапсов.

В продакшене работает ансамбль чекпоинтов.

**Объединение с визуальным сигналом (`fusion.py`).** Скрытая марковская
цепь по порядку фаз. Порядок и длительности фаз берутся из плана, даты не
используются. Модель по технике оценивается на каждом дне, когда площадку
снимали. Визуальные вероятности приходят из `visual_phase` для всех
записей проекта. Результат — P(фаза | все наблюдения до сегодня).
Устроено так:

- переход назад маловероятен (0.01 за шаг), поэтому одиночный выброс не
  откатывает фазу, а подтверждённый откат принимается;
- фаза не продвигается вперёд после последнего наблюдения, возраст
  оценки виден в `days_since_last_observation`;
- веса сигналов: техника 0.5, снимок 1.0, заполненные дни 0. Веса
  задаются переменными `PHASE_WEIGHT_*`.

## Качество

Оценка на размеченных таймлапсах. Каждый день ролика — отдельное
предсказание. Во всех случаях проверка идёт на стройках, которых модель не
видела при обучении.

**Модель по технике, 14 роликов, 8717 дней:**

| Версия | Точность | ±1 фаза |
| --- | --- | --- |
| константа «самая частая фаза» | 37.0% | — |
| v1 (синтетика) | 20.9% | 54.2% |
| v2 (симулятор детектора) | 38.6% | 62.4% |
| v2_ft (дообучение, leave-one-video-out) | 54.4% | 76.4% |

На 60 стройках (36 тыс. дней, 10 фолдов) v2_ft даёт 52.3% (±1 фаза:
75.4%), константа — 35.7%.

**Техника вместе со снимком, 60 строек:**

| Вариант | Точность | Средний recall по фазам |
| --- | --- | --- |
| только техника (v2_ft) | 52.3% | 27.4% |
| только снимок (SigLIP) | 55.5% | 32.1% |
| техника + DINOv2 (0.4 v2_ft / 0.2 v2 / 0.4 DINOv2) | 60.6% | 33.3% |
| техника + DINOv2 + SigLIP + SigLIP zero-shot | **66.4%** | 39.5% |

Цифра 66.4% получена при весах, подобранных сеткой на тех же днях,. На 14 роликах учёт истории (forward-фильтр)
добавлял ещё 1–1.5 п.п.

Для сравнения: предыдущая версия ансамбля, обученная на 14 роликах, на 46
новых стройках давала 53.2%.
 |

## Ограничения

- Модель хорошо узнаёт массовые фазы (каркас, отделка, земляные работы) и
  почти не узнаёт редкие (кладка, инженерные системы, пусконаладка): на
  них мало данных.

- Разметка таймлапсов ручная, по контактным листам. Границы фаз в ней
  приблизительные.
